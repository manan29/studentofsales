# Your takes

One file per move, named after the move's slug (the end of its URL):
`/moves/sdr-to-ae` → `sdr-to-ae.md`.

1. Open the file and write under each `## ` heading. The `<!-- ... -->` hints are never shown.
2. Leave `status: draft` while you work: it appears on Vercel previews with a "Draft" badge, not on the live site.
3. Change to `status: published` and commit. It's live about a minute later.

Sections with no text are skipped. If every section is empty, the page says the take is still being written.
